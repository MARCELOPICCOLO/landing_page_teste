# Gyn Batatas — Landing Page

Landing page estática em **HTML + CSS + JavaScript**, responsiva e preparada para conversão via WhatsApp.

## O que foi incluído

- Fotos gastronômicas realistas das batatas recheadas.
- Hero com foto de destaque.
- Cardápio com fotos para Frango, Carne Seca, Camarão, Vegetariana e Tradicional.
- Prova social / área de avaliações.
- Botões de pedido direcionando para o WhatsApp **(62) 98244-4759**.
- HTML semântico, textos alternativos nas imagens e carregamento otimizado.
- `robots.txt` e `sitemap.xml`.
- Meta tags SEO, Open Graph e Twitter Cards.
- Schema.org `Restaurant` / `LocalBusiness` em JSON-LD.
- Layout responsivo para celular, tablet e desktop.

## Antes de publicar

1. Substitua `https://www.gynbatatas.com.br/` pelo domínio real caso seja diferente.
2. Confirme endereço, horários, área de entrega, sabores, preços e demais informações da empresa.
3. Substitua os depoimentos de exemplo por avaliações reais, com autorização dos clientes.
4. Se a empresa tiver fotos próprias, prefira as fotos reais do estabelecimento/produtos nas versões finais.
5. Publique `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml` e a pasta `assets/` no mesmo domínio.
6. Cadastre e verifique o site no Google Search Console e envie o `sitemap.xml`.
7. Cadastre/verifique o site no Bing Webmaster Tools e envie o `sitemap.xml`; considere IndexNow para atualizações.
8. Mantenha o Google Business Profile atualizado com endereço, telefone, horários, fotos e avaliações reais.
