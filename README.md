# Gyn Batatas — Landing Page

Landing page responsiva feita somente com HTML, CSS e JavaScript.

## Arquivos
- index.html — página principal + SEO + Schema.org
- styles.css — layout responsivo
- script.js — interações simples
- robots.txt — permite rastreamento
- sitemap.xml — sitemap para buscadores

## Antes de publicar
1. Troque `https://www.gynbatatas.com.br/` pelo domínio real, caso seja diferente.
2. Atualize endereço, horários, cardápio, preços e depoimentos com informações reais.
3. Substitua os emojis/visuais de demonstração por fotos reais dos produtos para aumentar a conversão.
4. Publique os arquivos na raiz do domínio.
5. Cadastre o domínio no Google Search Console e no Bing Webmaster Tools e envie o sitemap.
6. Crie/otimize o Perfil da Empresa no Google para a localização real da Gyn Batatas.
